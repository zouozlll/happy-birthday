# Birthday Card 🎂 
Responsive Birthday Card - Made with Jquery and CSS


# How to Start the Program

> **同為資科系的應該是會吧，以防萬一還是寫一下README**

## Prerequisites

- A web browser (e.g., Chrome)
- Optionally, a code editor (like VS Code) for modifications

## Step-by-Step: Run in Terminal (Using a Local HTTP Server)

### 1. Navigate to the project folder

Open your terminal and `cd` into the project directory:

```bash
cd happy-birthday
```

#### Option A: Using Python (works if Python is installed)
    ```bash
    python3 -m http.server
    ```
    Then, open your browser and go to: http://localhost:8000
    
#### Option B: Using Node.js (if you have Node installed)
    Install http-server once:

    ```bash
    npm install -g http-server
    ```
    
    Then run:
    
    ```bash
    http-server
    ```

    It will show something like:Starting up http-server at http://127.0.0.1:8080
    Open that link in your browser.
